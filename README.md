# ভন্ড বাবা Laeeq 🧘

সকল সমস্যার ১০০% ভুল সমাধান — শুধুমাত্র মজার জন্য বানানো একটা ফানি ওয়েবসাইট।

## যা যা আছে
- পর্দা খুলে বাবার ঘুরে ঘুরে আগমন, কালো চশমা চোখে বসে
- সমস্যা বাছাই করো, বাবা বাংলায় (পুরুষ কণ্ঠে) উত্তর দেবেন
- ভন্ড-রাশিফল (ঘুরন্ত রাশিচক্র), বাবার ঘুম (নাক ডাকা + "ডিস্টার্ব করিও না")
- বাবার বিবর্তন, মিম, ভক্তদের অভিজ্ঞতা (অটো স্লাইডার)

## লোকালি চালাও
```
php -S localhost:8080
```
তারপর ব্রাউজারে `http://localhost:8080` খোলো। (অথবা Laragon দিয়ে `http://vondobabalaeeq.test`)

## বাবার ভয়েস নতুন করে বানাতে
`assets/js/app.js` এ কোনো বাংলা লাইন বদলালে:
```
pip install edge-tts
python tools/make_voice.py
```

> ⚠️ এই সাইট শুধুমাত্র মজার জন্য। বাবার কোনো অলৌকিক ক্ষমতা নাই — শুধু দাড়ি আছে।
